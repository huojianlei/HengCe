# 衡策 1.0.5 使用说明

## 安装与文件位置

运行“衡策-1.0.5-安装包.exe”，默认安装到 `D:\衡策\1.0.5`，无需管理员权限。演示版和正式版有独立的程序项，可与 1.0.4 并存。便携包可解压到 D 盘后直接运行 `FinAgent.exe`。数据、浏览器缓存和报告默认位于 `D:\衡策数据\1.0.5`；程序拒绝将数据目录或输出目录设在 C 盘。

卸载请先退出系统托盘中的衡策，再从 Windows“已安装的应用”或开始菜单运行卸载程序。模型 API Key 仅保存在当前页面内存，不写入分析文件。程序使用随包 Node、Python 和本地知识库；在线 AI 解读须用户自行配置接口。

## 导入与分析

1. 下载程序内的“唯一输入模板.xlsx”。必须保留 12 张表，填写 `AX:AY` 的主体、情景、年度、期间及版本元字段，在蓝色输入参数位置填数，保持公式结构。原始 2018 工作簿不能直接导入。
2. 把一份或多份 XLSX 拖入输入区。每份代表一个主体和一个情景；下拉框切换单组。选择“分析本批全部主体与情景”会分别保存各组 JSON，不混合情景。CSV、TXT、DOCX、PDF 等均退回。内部八字段记录仅供查阅。
3. 月度是基础粒度；季度模式将流量按三个完整月汇总。导入前自动重算公式并执行 452 项勾稽，缺表、改公式、外链、错误科目、错期间或三表不平即整本拒绝。
4. 可在界面填写阈值、BSC、KPI 和溯源等专业参数，再运行单组分析。预算、实际、采购和行业数值占位均清楚标注，不应作为真实经营判断。
5. 演示版面板输入固定种子、主体和情景，点“生成 Excel 并运行分析”或“导出 Excel 给老师查看”。同一种子产生相同的 Excel 内容；生成前先通过勾稽，再用真实引擎预跑。导出的工作簿可直接拖回输入区。

## 开发与验证

源码在 `D:\AppProject\开发分支_1.0.5`；旧 1.0.4 归档未改。`algo/excel_ingest.py` 实现 XLSX 解析与旧八字段适配，`algo/excel_generate.py` 实现种子生成。新增验证：`python -m unittest discover -s algo/tests -p test_excel_template.py` 与 `node --test desktop/tests/excel-api.test.mjs`。完整规格见 `D:\AppProject\docs\唯一Excel输入模板规格书-1.0.5.md`，脱敏复核报告见 `D:\AppProject\docs\脱敏与勾稽验收报告-1.0.5.json`。
