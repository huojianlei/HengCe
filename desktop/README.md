# 衡策 1.0.5 四类 Excel 输入说明

## 安装

运行 `衡策-1.0.5-安装包.exe`，默认安装到 `D:\衡策\1.0.5`。也可将便携 ZIP 解压至 D 盘运行 `FinAgent.exe`。报告与浏览器缓存默认存放在 `D:\衡策数据\1.0.5`。1.0.4 安装和归档保持独立。

## 四类文件

1. `预算基础输入模板.xlsx`：12 张工作表，来自获授权的预算表骨架，按月填写预算参数。元字段 `AX16:AY16` 为 `数据类别=预算基础`。
2. `实时经营输入模板.xlsx`：与预算基础**完全相同的 12 张表及输入位置**，另存一份填写已结账实际，`AX16:AY16` 为 `数据类别=实时经营`。季度分析只加总完整已结账季度的流量；资产和现金余额作为期末时点值校验。
3. `行业对标输入模板.xlsx`：`批次信息`、`基准指标`两表。真实参考值必须填写行业范围、样本、计算口径、来源网址、发布日期和适用限制；构造值必须明确标记。相同指标/期间/口径只能选一条生效来源。
4. `经营变更输入模板.xlsx`：`批次信息`、`事件台账`、`科目影响`三表。事件ID关联一项或多项科目；填写发生、生效、方向与影响值。已批准的事件必须同时提供申请人/日期、审批人/日期、结论和依据。程序检查字段一致性；审批权限真实性须按企业制度人工确认。

四类文件都只能使用对应固定 XLSX 结构；CSV、TXT、Word、PDF 等不会自动适配。每份文件的主体、情景、年度、粒度、数据版本、口径和生效周期需与同组其他文件一致。预算和实际是分析必需；行业对标、经营变更按需导入。不同主体或情景分别分析，不混合合计。两张预算底稿 `分录`、`摊销明细`保留在 12 表结构内，仅用于内部校验。

## 演示和复核

演示版输入固定种子，会分别生成四份标明“占位/构造参考值”的 Excel，自动核验公式及财务勾稽，再预跑真实分析引擎。同一种子、主体和情景产生相同文件内容；导出的四份文件可一次拖回输入区。BSC、KPI 等专业参数仍需在页面补充。

源文件、1.0.4 归档只读。模板规格、行业参考口径和零残留复核分别见 `D:\AppProject\docs\唯一Excel输入模板规格书-1.0.5.md`、`行业参考来源与口径-20260923.md`、`脱敏与勾稽验收报告-1.0.5.json`。开发源码在 `D:\AppProject\开发分支_1.0.5`。
