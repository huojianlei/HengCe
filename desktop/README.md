# 衡策 1.0.5 四类 Excel 输入说明

## 安装

本轮为三栏界面版，含空白黑白四模板、结果访问权限与用户指定 logo。运行安装包，默认使用 D 盘；也可解压便携包运行 FinAgent.exe。报告与缓存留在 D 盘。1.0.4 安装和归档保持独立。

## 四类文件

1. `预算基础输入模板.xlsx`：12 张工作表，来自获授权的预算表骨架，按月填写预算参数。元字段 `AX16:AY16` 为 `数据类别=预算基础`。
2. `实时经营输入模板.xlsx`：与预算基础**完全相同的 12 张表及输入位置**，另存一份填写已结账实际，`AX16:AY16` 为 `数据类别=实时经营`。季度分析只加总完整已结账季度的流量；资产和现金余额作为期末时点值校验。
3. `行业对标输入模板.xlsx`：`批次信息`、`基准指标`两表。真实参考值必须填写行业范围、样本、计算口径、来源网址、发布日期和适用限制；构造值必须明确标记。相同指标/期间/口径只能选一条生效来源。
4. `经营变更输入模板.xlsx`：`批次信息`、`事件台账`、`科目影响`三表。事件ID关联一项或多项科目；填写发生、生效、方向与影响值。已批准的事件必须同时提供申请人/日期、审批人/日期、结论和依据。程序检查字段一致性；审批权限真实性须按企业制度人工确认。

四类文件都只能使用对应固定 XLSX 结构；CSV、TXT、Word、PDF 等不会自动适配。每份文件的主体、情景、年度、粒度、数据版本、口径和生效周期需与同组其他文件一致。预算和实际是分析必需；行业对标、经营变更按需导入。不同主体或情景分别分析，不混合合计。两张预算底稿 `分录`、`摊销明细`保留在 12 表结构内，仅用于内部校验。

## 演示和复核

四份下载模板为空白黑白表单，固定表名、表头与公式保留，业务数值、主体与情景待填写。内部演示底稿和月/季测试夹具单独存放，不写入用户下载模板。新三栏页面支持导入填好的演示文件；演示版右栏另有固定种子生成入口，一次生成四份 Excel 后自动导入并分析，正式版不提供此入口。

经营变更台账只读呈现。没有经营变更文件时，对话栏主动询问；答“无”记录确认，答“有”须先登记事件与科目影响再导入。未确认时只出复核提示，不假设无结构性变化。首次导入弹窗可补充宏观背景；未配置模型时采用本机固定追问，叙述保留当前会话，不替代台账与审批。

数据访问每次请求默认关闭，关闭时问答与云端解读明确拒绝。开启后仅发送当前已核验计算结果的科目、期间、金额、差异率、模块与判定；不发送原始工作簿、来源备注、台账正文或文件路径。模型 Key 只经内存传递，不持久化。AI 进程执行阶段禁止读写文件、启动程序及连接非授权地址；这是应用执行边界，不是操作系统容器。正式构建拒绝本地生成模型组件，云端接口只接受 HTTPS。

看板按导入元字段切换主体与情景，收入/成本/费用/采购分别汇总，成本含人力。未填写的 BSC、KPI 和拆分参数明确显示缺失。
