# 衡策 1.0.5 四类 Excel 入口验收记录

验收日期：2026-09-23。开发分支目录：`D:\AppProject\开发分支_1.0.5`。交付目录：`D:\AppProject\dist\releases\1.0.5`。

用户原始 12 表工作簿只作为预算基础与实时经营共用版式的来源；这两类数据各交一份同版式文件，由每张表 `AX16:AY16` 的数据类别区分。行业对标与经营变更是各自固定版式。四类一律只收 `.xlsx`，解析后进入既有八字段结构，同主体/情景/年度/粒度/版本/口径对齐后才组合分析。

- 经营变更：三表固定表头；事件 ID 与科目影响关联，可一事件多科目。仅申请、审批、结论与依据完整且状态一致的已批准事件进入结构性变更判定。导入不自动修改已结账实际或预算，审批权限真伪需企业制度人工核实。
- 演示：固定种子产出四份 Excel，占位值只改输入参数或自编模板的演示记录；导出前重算预算和实际并预跑分析。同种子文件内容可复现，四份可重新导入。
- 质量：旧插件 216 + 旧桌面 31 = 247 项原回归通过、测试文件未改；新增模板 16 项、四类接口 4 项通过。浏览器双主体四文件导入、批量分析、种子演示、1024px 布局与零脚本错误通过。两个独立展开包均通过包内 Python 导入、季度演示生成及真实引擎探针。
- 脱敏：四个模板和八份月度/季度夹具均逐一做原件数值完整匹配与标识文本检索，零命中。1.0.4 的两处冻结目录及原始来源文件哈希未变。发布包内四模板哈希与已复核源文件一致，没有前一版的单本误模板和 QA 目录。
