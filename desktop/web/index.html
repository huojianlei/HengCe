常见问题
Q1.支持哪些文件格式？

仅支持四类固定 Excel 模板（.xlsx）。预算基础与实时经营共用 12 表版式；行业对标与经营变更使用各自固定版式。CSV、PDF、Word 等格式一律退回，不作格式适配。

Q2.一次可以导入几份文件？

不限份数。每份工作簿代表一个主体与一个情景，可同批导入、分别分析；同一主体、情景的同类别文件重复时需改用替换导入。

Q3.我的财务数据安全吗？

数据计算不出本机：工作簿解析、勾稽校验与全部数值计算都在本机完成，输出固定写入 D 盘。报告的文字部分需要云端大模型参与整合，为此会把计算结果（科目、期间、金额与判定）发送给所配置的模型接口，不上传原始工作簿；模型 API Key 仅保留在页面内存中，不写入任何分析文件。

Q4.AI 解读的准确性如何保证？

数值由确定性计算插件生成，AI 只负责文字解释，且回答需通过数字原文核验；未提供的依据不会作为事实引用。AI 结论仅供参考。

Q5.文件被整本退回怎么办？

常见原因：工作表缺失、公式被修改、存在外部链接、期间或科目填写错误、三表勾稽不平。请对照退回提示修正，或重新下载标准模板填写。

Q6.如何导出分析报告？

在右侧「报告导出」选择格式，点「生成报告」生成预览，点「保存到本地」写入输出文件夹；PDF 由报告页直接打印生成。输出文件夹可在左侧「帮助与设置」中修改。
