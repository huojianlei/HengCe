## 强制规则（违者不得合入）

1. **注释率 ≥ 40%**（含 docstring 与 # 注释，按非空行计）——用检查器验证：
   `../env/Scripts/python.exe tools/check_comments.py <文件...>`（检查器自身也在被检范围）。
2. **一模块一文件**：`rolling_budget.py`、后续 `variance.py`、`planning_operational.py`、`loop_decision.py`、`building_blocks.py`、`bsc.py`、`kpi.py`……
3. **知识点示例前置**（2026-08-23 用户指令，与"用 Python 写""注释量"同级）：每个模块 docstring 顶部写一段"使用示例（知识点速览）"，**doctest 格式**（`>>>` 可运行），像教程一样覆盖全部公开函数的典型调用与结果；写完 `python -m doctest <模块>.py` 验证，并在 `tests\test_demos.py` 的 TESTED_MODULES 登记——示例过时测试即红。
4. **标识符全拼音**（2026-08-23 用户指令，同为核心规则）：所有变量/函数/类/常量/字典键/命令行参数一律**无声调拼音**（函数与变量 snake_case、类 CamelCase、常量全大写，惯例保留）；**数据值用中文**（如周期 '月度'/'季度'、状态 '已届满'/'剩余期'）；文件名保持英文（Windows 规范）；专有缩写可保留（CSV、BSC、KPI、ACCA、LLM、F/A 记号）。
5. **数值纪律**：金额=整数分，增长率=基点 bps，全程整数运算，乘法 half-up 逐期舍入。
6. **纯函数**：无 I/O、无全局状态；期望值在测试中手算写死（禁止自证循环）。
7. **口径溯源**：每个模块头部 docstring 注明口径依据（定稿 v2.1 章节号 + TODO 编号），待拍板项用建议默认值并显式标注。

## 随机数据工具（tools/gen_data.py）

- **fuzz 模式**：随机生成合法输入（周期/期数/不等额预算/散布实际期/增长率/口径全随机），跑被测函数后用**独立影子算法**逐期互证 + 六条性质断言（P1 总额一致 / P2 差值定义 / P3 届满替换 / P4 影子一致 / P5 确定性 / P6 形态合法）+ 零增长恒等专项。`--seed` 固定可复现，省略则探矿。
- **fixture 模式**：随机数据落盘 JSON（`fixtures\`），演示数据集（T-14）与 bug 复现共用同一生成器。
- **战果**：首日运行即暴露口径歧义（等额预算例题无法区分"链式累进"与"各期原预算累进"），已切换为后者并登记 T-23——这就是随机测试的价值。
- 新模块接入：在 gen_data.py 补 `generate_<module>_case` + `shadow_<module>`，注册进 CLI。
