# 衡策工作台 UI 重建

## 玻璃与动效改版

按用户的新要求，整体升级为轻透的玻璃工作台。沿用蓝色主操作与红黄绿业务语义，增加统一的材质层次：环境底色 #EDF2F9；壳层白色 56% 不透明度 / 28px 模糊；数据面板白色 72% / 18px 模糊；弹窗白色 88% / 32px 模糊。圆角按壳层 24px、内容 20px、操作 12px 分层。背景采用静止的浅蓝环境光，数字和长文本仍位于较实的表面。

动效采用快速起步、缓慢收敛的非线性曲线；导航背景连续滑移，页面作为一个工作面进入，助手与抽屉有轻微弹性，按钮有按压与释放反馈。避免所有卡片同时浮动或无限装饰动画。遵循系统“减少动态效果”设置；不支持背景模糊时回退为实色表面。

新材质集中在 `src/玻璃主题.css`，动效集中在 `src/动效.mjs`，可单独替换，业务接口保持一致。

下拉菜单使用 `src/下拉菜单.mjs` 与 `src/下拉菜单.css` 统一呈现，包括部门、预警、分析周期、整改状态、修订期间、经营变更与导入方式。菜单沿用玻璃边缘、选中勾选和非线性展开；点击外部或按 Esc 关闭，方向键移动、Enter 确认，Tab 继续正常焦点顺序。原 select 仅作为隐藏数据源，保留表单与业务 change 事件。

窄屏侧栏使用独立可点击遮罩：点击侧栏外的空白区域或按 Esc 收起，点击侧栏内部空白保留展开；背景页面暂时不可操作，避免关闭时穿透点击。收起后焦点回到导航按钮，隐藏侧栏退出键盘焦点顺序。

页面整体进入 480ms，导航胶囊滑移 500ms，助手宽度过渡 480ms，弹窗进入 420ms、退出 180ms。所有业务 DOM 更新仍同步执行，动画不延迟提交或控制业务状态；同页筛选不重复入场。助手使用实际宽度插值，数字不参与缩放。快速连续操作会取消旧动效并收敛到最新状态。关闭弹窗具有身份检查与限时回退，旧回调不会清空新弹窗。

## 设计方向

主任务是沿着“数据准备 → 发现差异 → 判断原因 → 跟踪处理 → 形成报告”开展财务分析。页面优先给出当前分析口径、关键差异和下一步行动。

- 基底：工作区 #EDF2F9，静止的浅蓝/淡紫环境光，白色半透明内容层与高光边缘。
- 文字：主文字 #233550、辅助 #72839C；数据与长文本所在面板增加不透明度。
- 主色：操作蓝 #3168E9；有利/正常 #188575、关注 #B7791F、风险 #C54D57。
- 字体：数字使用 Bahnschrift / Segoe UI 的等宽数字；中文优先 Microsoft YaHei UI。页面标题 24px，正文 13px，数据 28px。
- 左侧 200px 浮动导航，距窗口边缘 12px；顶栏承载主体与时间；内容为可伸缩的经营工作区。AI 在右侧按需打开，窄屏使用覆盖层。
- 趋势图使用实线/虚线区分实际、预算与未来滚动值，同时提供图例和数值表。色彩不作为唯一信息。

```
┌────────────┬───────────────────────────────────┐
│ 衡策       │ 当前主体 / 情景       期间 · 助手  │
│            ├───────────────────────────────────┤
│ 经营总览   │ 标题、分析状态         主要操作    │
│ 数据工作区 │ 关键数字 / 预算参照                │
│ 差异分析   │ 趋势                    待处理事项│
│ 风险与整改 │                                   │
│ 组织部门   │ 差异明细 / 上下文操作             │
│ 报告中心   │                                   │
│ 分析记录   │                                   │
└────────────┴───────────────────────────────────┘
```

## 设计审视

避免为每个数字建立同等重量的卡片：关键指标组成一个连续摘要区；明细以表格表达；风险使用紧凑清单。主页面不常驻导入框，腾出空间呈现实际分析工作。圆角、阴影仅在必要的容器和覆盖层使用。

## 范围

这是可运行的 UI 与状态交互层。演示数据明确标记；本地上传文件不会假装通过 Python 校验；真实宿主模式绝不回退到演示结果。金额按整数分、比率按基点传输。业务计算、知识库、模型调用与审批落盘由未来 DSH 插件负责。
