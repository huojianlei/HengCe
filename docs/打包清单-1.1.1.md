## 一、前端只需要对接 3 个 Python 函数（+1 个联调 CLI）

新版前端（Electron/Tauri/Web+本地服务都行）**不用碰任何业务逻辑**，只要按顺序调这三步：
`导入 → 分析 → 报告`。三步都是纯函数，无副作用（报告会写文件），不需要常驻进程。

### 1.1 导入（上传 xlsx）

```python
from excel_ingest_v11 import import_excel_v11
jieguo = import_excel_v11(data: bytes, name: str) -> dict
```

| 项 | 说明 |
|---|---|
| 入参 | `data` = xlsx 文件字节；`name` = 文件名（必须以 `.xlsx` 结尾） |
| 轨道 | 自动分派：**12 表**（v1.1/v1.2 老契约）/ **9 表**（v2 演示件）/ **外部两册**（行业对标、经营变更） |
| 异常 | `xlsx_reader.ExcelError`，`str(e)` 是可直接展示的中文文案（如「固定表头或科目被修改：利润表!B23」） |
| 耗时 | 9 表约 1~2 s；12 表约 2~3 s |

返回 dict 的键（三种轨道略有差异，前端按存在即用）：

| 键 | 类型 | 含义 |
|---|---|---|
| `ok` | bool | 通过标记（失败会抛异常，不会返回 False） |
| `contract_version` | str | `v2` / `v1.1` / `v1.2` / 外部册缺省 |
| `category` | str | `预算基础` / `实时经营` / `行业对标` / `经营变更` |
| `metadata` | dict | 十六个元字段（主体名/编码/年度/粒度/已结账截至/数据类别…） |
| `checks` | int | 校验计数（v2 约 1.3 万项、v1 为 226 勾稽） |
| `records` | dict | 八字段入库结果：`yusuan / shishi / hangye / biangeng / jujue` 五个列表 |
| `ruku_shu` | int | 入库行数 |
| `subjects` | list | 科目清单 `{kemu, module, direction, accountCode}` |
| `groupKey` | str | 分组键 JSON（合并同主体同期间的多本时用） |
| `text` | str | 八字段 CSV 原文（复核/导出用） |
| `three` `shuijin` `tanxiao` `fenlu` `sheets` | — | 仅 v2 轨：三表快照、税金分项、摊销台账、逐笔分录（前端做明细页可直接用） |

> **预算 + 实际要一起导**：`预算基础` 提供 12 个月预算行，`实时经营` 提供已结账月实际行。
> 合并方式：两份 `text` 拼一起（第二份去掉表头）再交给 `data_ingest.daoru_csv`，见 `跑衡策全流程.py:pao_daoru`。

### 1.2 分析（十五步）

```python
from yinqing import fenxi
jieguo = fenxi(shuru: dict, xiuding_lie: list | None = None) -> dict
```

`shuru` 结构（与桌面 API 同形）：

| 键 | 必填 | 说明 |
|---|---|---|
| `records` | ✅ | 1.1 的 `records`（或合并后的 DaoruJieguo） |
| `subjects` | ✅ | 1.1 的 `subjects` |
| `config.cycle` | ✅ | `月度` / `季度` |
| `config.period` | ✅ | 分析末档，如 `2027-06` / `2027-Q2` |
| `config.growth` | ✅ | 企业增长率（**基点整数**，0 = 不增长） |
| `config.industry` | 可空 | 行业增长率（基点）；`None` = 不启用行业口径 |
| `config.industryCorrection` | ✅ | 季度是否启用行业差值修正 |
| `config.industryThreshold` / `noise` / `significance` | ✅ | 三个门限（基点，非负） |
| `config.tiers` | ✅ | 预警档位 `[{ming_cheng, yan_se:#RRGGBB, yu_fen:基点}]` |
| `company` / `metadata` | ✅ | 主体名与主体/情景编码（写报告抬头） |
| `bsc` `kpi` `traces` `splits` `events` `baselines` `changeStatus` | 可空 | 前端暂无对应功能时传 `None` / `{}` / `[]` |
| `xiuding_lie`（第二参） | 可空 | 人工批准的预算修订案 `[{kemu, period, amount, ...}]` |

返回 19 个键（`schemaVersion` 固定 `'1.0'`，金额=分、比率=基点）：

| 键 | 类型 | 前端用途 |
|---|---|---|
| `meta` | dict(13) | 抬头：company / period / scenarioName / entityCode / generatedAt / moneyUnit / rateUnit / simulation |
| `config` | dict(9) | 回显本次配置（前端表单回填） |
| `rolling` | list(18) | 滚动预算逐期明细 → 滚动预算页 |
| `variance` | `ChayiJieguo` | 差异与预警 → 差异分析页 |
| `decisions` | list(108) | 整改清单 → 整改页 |
| `blocks` | `JimuJieguo` | 积木（价差/量差）→ 积木页 |
| `dashboard` | `KanbanShuju` | 看板卡片 |
| `factors` | `XishuBao` | 系数包（完成率/预警分布等） |
| `kpi` | `KpiJieguo` | KPI 页 |
| `bsc` | None | 平衡计分卡（本版未评分） |
| `moduleSummary` | list(4) | 模块汇总表 |
| `correction` | `SimpleNamespace` | 行业修正结果 |
| `warnings` | list | 缺失提示（前端做黄色提示条） |
| `revisions` / `splits` / `trace` / `records` / `subjects` | — | 回显与溯源 |

异常：`yinqing.YinqingCuowu`，`str(e)` 可直接展示（如「请先导入年度预算」「分析期间格式与滚动周期不一致」）。

### 1.3 报告（md + html）

```python
from baogao_liuxian import compute_report_pipeline
r = compute_report_pipeline(jieguo, wencai_hanshu=None, zongjie_hanshu=None,
                            jiansuo_hanshu=None, shuchu_mu=None)
# → {'md': 路径, 'html': 路径, 'mokuai_shu': 9, 'tiaoli_shu': 72}
```

- `wencai_hanshu(模块名, 数据块) -> str`：逐模块分析文案；缺省用确定性占位（标注「由 DSH 宿主 agent 回填」）
- `zongjie_hanshu(jieguo) -> str`：总体解读；缺省同上
- `jiansuo_hanshu`：`None`=自动懒加载 kb2 真检索；`False`=关闭（条例落「未检索到直接依据」）
- `shuchu_mu`：输出目录（默认 `报告组装/输出`），写 `计算报告-月度.md` + `.html`

**PDF 不在 Python 侧生成**：前端拿到 `html` 后用壳层打印（Electron `webContents.printToPDF`，或 Chromium `--headless --print-to-pdf`），文件名建议 `计算报告-月度.pdf`。

## 二、数据契约（前端只需知道这三点）

1. **八字段 CSV**（入库与合并的唯一形态）：
   `数据类别,统计周期,数据科目,数值,单位,数据来源,更新时间,备注`
   金额单位＝**元**（两位小数），进分析引擎时内部换算成**分**。
2. **工作簿表序列**：
   - 12 表：`利润表 资产负债表 现金流量表 收入非主控 收入主控 税金及附加 销售费用 管理费用 蓝恐龙费用 费用表月度汇总 摊销明细 分录`（老轨，仅兼容）
   - **9 表（当前 v2 演示件）**：`利润表 资产负债表 现金流量表 税金及附加 销售费用 管理费用 费用表月度汇总 摊销明细 分录`
   - 外部两册：`批次信息+基准指标`（行业对标）、`批次信息+事件台账+科目影响`（经营变更）
3. **三表版式**：财会〔2019〕6 号（利润表/现金流量表 = 本期 B + 上期 C；资负 = 左 B/C、右 E/F）。

## 七、给前端的最小实现顺序

1. 上传两本 xlsx（预算基础 + 实时经营）→ 调 `import_excel_v11` → 展示 `metadata`（主体/期间/校验数）
2. 配置表单（周期/期间/增长率/门限/预警档位）→ 调 `fenxi` → 用 `variance` + `rolling` + `decisions` 渲染三块主视图
3. 「生成报告」按钮 → 调 `compute_report_pipeline` → 拿 `html` 用 `printToPDF` 出 PDF + 「打开所在目录」
4. 错误处理：只捕获 `ExcelError` / `YinqingCuowu`，把 `str(e)` 原样弹给用户（文案已中文化）
