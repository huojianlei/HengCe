# 衡策 UI 重建

这是一套独立可运行的前端，包含七个业务页面与完整演示交互。源码使用原生 JavaScript ES Modules，无需安装 npm 包，无构建步骤。旧版前端与 Python 后端未修改。

## 打开界面

双击 `启动预览.cmd`，然后访问：

- 独立工作台：http://127.0.0.1:4178
- 宿主嵌入布局：http://127.0.0.1:4178/?embedded=1

也可在本目录运行 `node 启动预览.mjs`。需要 Node.js 18 或以上；本机已配置 Node 22。端口可通过 `HENGCE_UI_PORT` 指定。服务仅监听本机回环地址。

嵌入布局隐藏独立侧栏，将七个业务页改为顶部页签，便于放入 DSH 的插件视图。默认页可用哈希定位，例如 `?embedded=1#risks`。

## 已实现的页面与交互

- 经营总览：核心经营指标、收入趋势、预算与滚动预测、重点事项、差异摘要。
- 数据工作区：四类工作簿、追加/替换、拖拽、逐文件移除、校验状态、经营背景。
- 差异分析：模块/部门/预警筛选、搜索、差额排序、科目详情、来源、CSV 明细导出。
- 风险与整改：三列状态看板、处理状态变更、单双环判定、人工预算修订、修订记录。
- 组织部门：部门经营数据与差异影响，下钻到对应分析范围。
- 报告中心：生成与预览；HTML、Markdown、JSON 下载；浏览器打印为 PDF。
- 分析记录：查看本次演示的历史快照。
- 分析设置：月/季、期间、增长率、行业修正、门限、档位名称/颜色/阈值。
- 按需展开的助手：当前科目与部门上下文、数据授权、提问与来源显示。
- 统一玻璃下拉菜单：部门、预警等级、分析周期、整改状态、修订期间、经营变更与导入方式共用同一套自绘菜单，原生 select 仅作隐藏数据源；支持键盘操作、点击外部与分层 Esc 关闭。

## 当前演示边界

演示数据为虚构的 2027 年 6 月经营数据，刷新页面会重置。预算、实际、差额与趋势使用一致的整数分数据。

选择本地 Excel 只进入“待校验”，不会假装完成解析；真实文件校验与财务计算由未来插件完成。演示修订仅记录审批交互，不执行滚动预算重算。演示问答不是模型回答，不提供虚构法规引用。正式空白模板需通过插件提供。

真实宿主存在时，任何失败都会显示错误，绝不回退到演示数据。缺少趋势、KPI 或评分时保留空状态。

## 交给拼接 agent

1. 先读 `接入说明.md` 和 `界面契约.d.ts`。
2. UI 启动前注入 `window.hengceHost`，把本项目协议转换为实际 DSH 插件工具/IPC。
3. 用 `workspace.load` 返回真实的 normalized workspace。
4. 依次接通导入、分析、整改、修订、报告、会话与历史。
5. 按接入说明逐项验收。UI 定义的桥协议不是 DSH 官方 API；应使用实际宿主能力实现它。

关键文件：`src/主界面.mjs` 是页面与交互，`src/界面.css` 是基础布局，`src/玻璃主题.css` 是统一玻璃材质与交互样式，`src/下拉菜单.mjs` 与 `src/下拉菜单.css` 是统一自绘下拉控件（原生 select 仅作隐藏数据源），`src/动效.mjs` 是非线性过渡，`src/业务桥.mjs` 是唯一业务调用边界，`src/演示数据.mjs` 是可替换夹具。接入时保留金额分、比率基点，复用已验证的 Python 计算结果。

玻璃主题在基础样式后加载。动效采用 Web Animations API，不依赖第三方动画库；尊重系统“减少动态效果”。宿主卸载插件时，可调用 `installMotion()` 返回的清理函数。导航、页面、弹窗和助手都使用同一套曲线与材质，避免拼接时重新引入原客户端的卡片边框与弹窗皮肤。

## 本地检查

`node 验收数据.mjs` 检查演示数据关系。`验收交互.py` 使用 Playwright 和本机 Chrome，服务启动后可运行；`验收动效.py` 验证非线性过渡、快速连续操作、弹窗竞争、减少动态效果与完成事件缺失时的回退；`验收菜单.py` 验证自绘下拉菜单与窄屏侧栏（加 `--sidebar-only` 只跑侧栏部分），公共操作封装在 `验收辅助.py`。验收截图与结果保存在 `验收截图/`。这些检查只证明 UI 行为，不替代真实 DSH 接入与财务后端验收。

本次玻璃版 + 下拉与侧栏修复验收：业务交互 16/16、动效 8/8、玻璃回归 7/7、下拉菜单与窄屏侧栏 12/12 通过；补充回归包含七页 × 三种窗口尺寸（1440/1024/390）× 独立/嵌入两种模式，共 42 组布局。下拉菜单覆盖部门、预警等级、分析周期、整改状态、修订期间、经营变更与导入方式，含键盘操作、分层 Esc、点击外部关闭与焦点恢复；窄屏侧栏点击遮罩关闭、焦点回按钮、背景防穿透。保存设置、整改与修订后的焦点恢复，助手显式输入焦点，以及移动菜单 440ms 进入 / 220ms 退出均已复验。无浏览器错误。
