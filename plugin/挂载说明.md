# 衡策 dsh 插件 · 挂载说明

> 版本 1.1.1 ｜ 适用：DeepSeek Harness 桌面客户端（0.2.x，Windows）
> 本插件为树外插件：不改 dsh 内核、不动官方 bundle，卸载即净。

## 一、插件构成

```
plugin\
├─ index.ts            dsh 入口：/hengce 前缀路由 + 4 个工具 + persona
├─ adapter\            Node 适配层：Python 桥进程、HTTP 服务核心、页面宿主桥、独立服务
├─ ui\                 液态玻璃工作台（原生 ESM，零构建零依赖）
├─ backend\            1.1.1 Python 权威后端（导入→十五步分析→报告，全绿自检）
│  └─ _vendor\         自足依赖：algo×17、kb2×4+模型、桌面模板、四类空白模板
├─ 数据\               运行时状态（状态.json、报告产物；随用随建，可整目录删除重置）
└─ docs\               接入说明、界面契约等
```

## 二、挂载方法（三选一）

### 方法 A：dsh 自己装（推荐，一条命令，已实测）

退出 dsh 桌面端后执行（cmd 里直接跑）：

```
dsh plugin --profile desktop add file:D:/AppProject/衡策源码/plugin
```

自动完成：pnpm 安装到档目录 → 登记 bundles → 按包名挂载（跨机器可移植）。
卸载同样一条：`dsh plugin --profile desktop remove @hengce/hengce-dsh-plugin`。

### 方法 B：cordis.patch.yml 追加一行（手工，热载约 1 秒）

先退出 dsh 桌面端，在文件末尾追加：

```yaml
- insert:
    - id: hengce
      name: 'file:///D:/AppProject/衡策源码/plugin/index.ts'
```

路径以 `plugin\index.ts` 的实际落位为准（必须 `file:///盘符:/...` 三斜杠写法）。
保存后启动 dsh 即生效；临时停用把该行改成 `- id: hengce` + `disabled: true`。

> 本机桌面档配置文件位置：`D:\dsh-desktop-data\dsh-home\profiles\desktop\cordis.patch.yml`

### 方法 C：独立服务（不动 dsh，演示/验收兜底）

```sh
cd plugin
node adapter/独立服务.mjs        # http://127.0.0.1:4180/hengce/（HENGCE_PORT 可改）
```

与方法 A 共用同一套处理器与状态，行为一致。

## 三、Python 运行时（跨机器口径）

插件计算走 Python，解释器按四级链自动发现：

1. `HENGCE_PYTHON` 环境变量显式指定；
2. 本机开发环境 `D:\dev-env\Python312\python.exe`（含 onnxruntime，条例检索满血）；
3. **dsh 桌面端自带托管 Python**（`<DSH_HOME>\dsh-runtimes\*\dependencies\python\python.exe`，
   3.12.14 + numpy + openpyxl）——任何装了 dsh 的电脑都具备；
4. PATH 里的 `python`。

能力分级（已实测）：

| 能力 | 依赖 | 缺失时行为 |
|---|---|---|
| 导入校验 / 十五步分析 / 报告 md+html+PDF | openpyxl（dsh 自带） | ——主链在纯 dsh 机器上开箱即用（实测 19 键/108 整改/9 模块/18 页 PDF） |
| 报告「依据条例」真检索（72 处出处） | onnxruntime + vendored bge 模型 | 自动降级为"未检索到直接依据"占位，不报错；`pip install onnxruntime` 后满血 |

## 四、挂载后自检（三条，全绿即成功）

1. 浏览器开 `http://127.0.0.1:<webserver端口>/hengce/`：左上显示"已连接衡策插件"，
   无"演示"字样，主体为导入工作簿的真实主体；
2. 对话里让模型调 `hengce_open_ui` → `hengce_import`（传 xlsx 路径）→ `hengce_analyze`
   → `hengce_report`，应依次返回导入校验数、差异/整改计数、报告页数；
3. 界面内：导入两册演示件（`backend\演示生成器v2\输出\`）→ 运行分析 → 生成报告 → 导出 PDF。

## 五、已知边界（如实登记）

- `assistant.ask` 由宿主对话承担（界面内助手会如实提示改用主对话窗口）；
- 报告内 AI 解读为确定性占位文案，标注"由 DSH 宿主 agent 回填"；
- 部门维度当前数据源不含，部门筛选只有"全部部门"；
- 报告再生成仅限本进程内做过的运行（重启后旧报告文件仍可导出，重新分析可再生成）；
- 历史快照与状态存于 `plugin\数据\`，删除该目录即完全重置。
