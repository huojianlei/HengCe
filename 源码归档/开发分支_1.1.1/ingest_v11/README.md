## 三、v1.1 校验规则（③）

1. **老区零改动**：12 表表名/元字段 AX1:AY16/月度表头/科目行校验/94 项年度小计与 **226 项勾稽**逐字保留——`reconcile` 与 1.0.5 完全一致；
2. **白名单扩容**：`cells = 老 ∪ 新`（标签/公式/输入全量），**非白名单格仍然拒收**（`{sheet}出现标准模板以外的单元格`）；
3. **镜像层**：触格即全量 + 逐字钉死（`镜像公式被修改：…` / `镜像公式缺失：…`）；
4. **功能区骨架**：触区即骨架齐（标签+公式逐字，`功能区标签/公式缺失或被修改：{区名}（格位）`）；输入格类型钉死（数值位只认真数值）+ 金额域（非负、≤90 亿）；
5. **新区恒等式**（激活才核，未填列月份按"无发生额留空"跳过；计数入 `result['zone_checks']`，226 计数不动）：
   - 利润披露 2 条：非流动资产处置损失 ≤ 营业外支出；对联营合营投资收益 ≤ 投资收益（年度）；
   - 现金流明细 12 条：直接法期末现金 == 月度间接法区行 68（逐月）；
   - 税种分档 12 条：分档合计行 == 税金及附加 C..N 33（逐月）；
   - 摊销台账 12 条：矩阵合计行 == 本月摊销 C..N 33（逐月）；
   - 分录全账 1+N+M 条：全年借贷平衡 + 逐月借贷平衡 + 现金流对照逐（行,月）与现金流明细互证；
6. 功能区数据按"内部底稿与勾稽依据"口径读入 `result['zones']`（不进八字段业务行）；行业对标/经营变更两版式复用 1.0.5 `external_templates`（只读引用）。
