# 衡策演示生成器（1.1.1 · v1.1 契约扩容版）

重写四类演示 Excel 的生成器，解决旧版演示文件"前 6 表大量空白、内容缺失"的问题。
以 1.0.5 演示底稿网格为唯一版面，只做"填空 + 按契约补齐"，零 C 盘，1.0.5 树与
老师原件全程只读。

## 用法

```bash
# 生成四类演示文件到 ./输出/
python gen_four_books.py [--seed 20260923] [--entity 衡策中学] [--scenario 基础情景] ...

# 一条命令验收（生成 → 结构断言 → import_excel 226 项勾稽 → 密度 → 黑名单 → 确定性）
python verify.py
```

## 模块

| 文件 | 职责 |
|---|---|
| gen_four_books.py | CLI 入口：生成预算基础/实时经营/行业对标/经营变更四份 xlsx |
| twelve_book.py | 十二表编排：契约补齐（利润表 C7/C8/C9、资负营运资本链等）+ 输入层重写 |
| demo_model.py | 确定性业务数值层（固定种子；收入/成本/费用/摊销参数；黑名单避让） |
| external_book.py | 行业对标/经营变更演示行（复用 1.0.5 external_generate.populate，只读） |
| xlsx_patch.py | 受限 XML 手术写出：保版面/样式/合并区，公式按 Book 引擎重算缓存 |
| verify.py | 验收器：34 项断言，写 验收报告.md |
| _scan1_census.py / _scan2_detail.py | 过程检查脚本（第二步底稿普查/细查，只读；报告见 _过程检查/） |

## 关键设计

- **格子红线**：写格范围 ⊆ 契约 cells 白名单；文本标签除白名单（元数据/动态标题/
  契约改写 B62）外逐字冻结；公式格位置集合 == 契约公式位全集（底稿缺的 13 位按
  契约补齐）；行列规模 A1:AY480 不变。
- **勾稽**：226 项（12 月 × 11 项月度勾稽 + 94 项科目年合计）由公式链自动满足；
  行 20 折旧摊销 = 摊销明细月摊销（公式直连）。
- **确定性**：固定 ZIP 时间戳 + 种子化数值，同参数逐字节复现（verify 实测）。
- **黑名单**：非零数值 100% 避开老师原件数值哈希；零值为结构性中性值豁免。

## 已知边界（详见 验收报告.md 第二节）

底稿缺行项目（利润表营业外/投资收益/每股收益数值位、资负主体区科目位、现金流
明细行、收入宽表字段、税种明细、摊销台账、分录全账等）不在契约白名单内，本轮
按"无发生额留空"处理，留待版本决策。
